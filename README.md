# Word Garden · 英语单词积累

一份莫奈色系的英语单词卡片模板。页面采用柔和的鼠尾草绿、睡莲蓝、雾紫和暖桃色，适合长期积累词汇。

## 使用方式

- 点击卡片内的文字即可直接修改单词、音标、词性、释义、搭配、例句和笔记。
- 点击“新建单词”添加空白卡片。
- 输入新单词后离开输入框，页面会自动查询音标、词性、中文释义和例句；也可以随时点击卡片右上角的“自动补全”。
- 使用顶部搜索框按单词、释义或笔记查找内容。
- 使用“学习中 / 待复习 / 已掌握”整理学习进度。
- 修改会自动保存到网站后端数据库，关闭网页或更换浏览器后重新打开也不会丢失。
- Note 支持 Markdown：标题、粗体、斜体、行内代码、引用和无序列表均可预览。
- 可以新建多个词汇页、切换页面，并直接修改当前页名称；每一页独立保存自己的单词。
- 点击“下载当前页 PDF”只导出正在查看的页面，文件名为“当天日期 英语词汇积累 - 页面名称”。
- 支持文件保存选择器的浏览器会先让你选择位置；其他浏览器会直接保存到默认下载文件夹。
- PDF 使用紧凑字号与间距，并以整张卡片为换页单位，避免单词卡片在页尾被截断。

## 自动补全的数据来源

- Free Dictionary API：英文音标、词性、释义和例句。
- MyMemory：将英文释义翻译为中文。

两项服务均通过项目内的 `/api/enrich` 接口调用，不需要在浏览器中填写密钥。自动补全依赖网络，公开服务繁忙时可以稍后重试，所有内容仍可手动修改。

## 数据保存

- 所有词汇页、页面名称、单词卡片和学习状态保存在网站后端 D1 数据库。
- 页面会显示“保存中 / 已保存 / 保存失败”，便于确认同步状态。
- 升级前的浏览器记录会在首次打开时自动迁移到后端，迁移成功后删除旧浏览器记录。
- `/api/notebook` 负责读取和保存完整词汇本。

## 本地预览

安装依赖后运行开发预览：

```bash
pnpm install
pnpm run dev
```

然后在浏览器中打开终端显示的本地地址。

## 主要文件

- `app/page.tsx`：卡片内容、编辑逻辑与示例单词。
- `app/globals.css`：整体布局、莫奈色系、卡片样式和移动端适配。
- `app/layout.tsx`：页面标题与简介。
- `app/api/enrich/route.ts`：在线词典与中文翻译接口。
- `app/api/notebook/route.ts`：后端词汇本读取与保存接口。
- `db/schema.ts`：词汇本数据库结构。
